# Solana builds — workspace

This repository was the original workspace for several Solana projects. Each
project now lives in its own dedicated, standalone repository — use those:

| Project | Repo | What it is |
| ------- | ---- | ---------- |
| **fair-tickets** | https://github.com/G-ojies/fair-tickets | Event ticketing as a Solana program with a **program-enforced fair-resale price cap** (anti-scalping). Anchor/Rust + TypeScript CLI, deployed to devnet. |
| **onchain-rbac** | https://github.com/G-ojies/onchain-rbac | Role-Based Access Control as a Solana program — organizations, roles, permission bitmasks, and runtime-enforced guards. Anchor/Rust + TypeScript CLI, deployed to devnet. |
| **ghost-protocol** | https://github.com/G-ojies/ghost-protocol | Autonomous Superteam Earn agent — discovers, scores, and submits to listings; watches the public + agent boards with Telegram alerts. |

> The copies under `Development/` in this repo are kept for history. The
> standalone repos above are the source of truth and where active work happens.
